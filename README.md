# Local-first, evidence-led tools

I build local-first, evidence-led tools for operations, e-learning QA, and research.

## Featured public work

- [Discovery Workbench](https://github.com/jarrettdustinqq/discovery-workbench) — a research-preview workspace with a live public demo ([open demo](https://jarrettdustinqq.github.io/discovery-workbench/)).
- [Phantom Shell](https://github.com/jarrettdustinqq/phantom-shell) — shell automation with integrity and tamper-evidence guardrails.
- [Fleet](https://github.com/jarrettdustinqq/jarrettdustinqq-fleet) — bootstrap and Control Hub tools for local operations.
- [CourseZip Check](https://github.com/jarrettdustinqq/coursezip-check) — course-archive QA and preview tooling ([latest preview, v0.1.1](https://github.com/jarrettdustinqq/coursezip-check/releases/tag/v0.1.1-preview)).
- [Etsy Seller Prompt Pack](https://github.com/jarrettdustinqq/etsy-seller-prompt-pack) — a small public landing page for an Etsy prompt-pack resource ([open landing page](https://jarrettdustinqq.github.io/etsy-seller-prompt-pack/)).

## Working principles

- Prefer inspectable evidence over unsupported claims.
- Keep operational and recovery work separate from public demos.
- Build small, useful tools before expanding their scope.
